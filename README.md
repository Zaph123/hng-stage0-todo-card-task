# Todo Item Card — HNG Stage 0

A simple, responsive Todo Item Card built with HTML, CSS, and Vanilla JavaScript. This was created as part of the HNG Internship Stage 0 task.

## Features

- **Responsive Design**: The card layout adapts to different screen sizes.
- **Dynamic Time Remaining**: Calculates and displays the time remaining until a set due date.
- **Interactivity**: 
  - Checkbox to toggle the task's completion status.
  - Automatically updates a status badge when the task is marked as done.
- **Micro-interactions**: Subtle hover and active states for buttons and the checkbox to ensure a polished user experience.

## Usage

1. Open `card.html` in any modern web browser to view the card.
2. Click the checkbox to toggle the task status.
3. Observe the "Time remaining" update automatically.

## Tech Stack

- **HTML5**: Semantic markup for structure.
- **CSS3**: Custom properties (variables) for consistent styling, flexbox/grid for layout, and media queries for responsiveness. No external CSS frameworks were used.
- **JavaScript**: Vanilla JS for logic (handling the checkbox state and calculating time remaining).
